# AdminSystem 项目规则

## 技术栈

1. Vite
2. React + React Router
3. TypeScript
4. Ant Design
5. Tailwind CSS

## 项目结构

```
apps/adminSystem/
├── src/
│   ├── pages/          # 页面组件
│   ├── network/        # 网络请求封装
│   ├── request/        # API 请求函数
│   ├── store/          # 状态管理
│   └── utils/          # 工具函数
├── public/             # 静态资源
└── package.json
```
