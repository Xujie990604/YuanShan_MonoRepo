# 设备概况插件化方案

## 1. 背景与目标

### 1.1 背景
- 应用对接阵列服务器，需要展示服务器信息概况
- 会外接第三方服务器，但不想为每个第三方做定制开发
- 需要将"设备概况"区域做成可插拔的组件

### 1.2 目标
- **解耦**：主应用与第三方展示逻辑解耦
- **灵活**：第三方可以自定义样式和排版
- **统一**：API 接口字段统一，保证数据一致性
- **易用**：第三方只需提供 Web Components 的 JS 文件即可集成

### 1.3 当前阶段（DEMO）
- ✅ **简化设计**：插件只负责样式布局，不处理异常情况
- ✅ **数据传递**：主应用调用 API，将数据传递给插件
- ✅ **功能聚焦**：先实现核心功能，后续再完善错误处理、性能优化等

## 2. 技术方案

### 2.1 技术选型：Web Components

**为什么选择 Web Components？**
- ✅ 框架无关：不依赖 React/Vue/Angular 等框架
- ✅ 原生支持：浏览器原生支持，无需额外运行时
- ✅ 样式隔离：Shadow DOM 提供天然的样式隔离
- ✅ 标准化：W3C 标准，兼容性好
- ✅ 易于集成：第三方只需提供 JS 文件，主应用动态加载

## 3. API 规范定义

### 3.1 设备概况 API

**接口地址：**
```
GET /api/v1/devices/:serverId/overview
```

**认证：**
- 需要 JWT Token（通过 Authorization Header 传递）

**请求参数：**
- `serverId` (path): 服务器 ID

**响应格式：**
```typescript
interface DeviceOverviewResponse {
  code: number;
  data: DeviceOverviewData;
  message: string;
}

interface DeviceOverviewData {
  // 设备基本信息
  deviceInfo: {
    id: string;              // 设备 ID
    name: string;            // 设备名称
    ip: string;              // IP 地址
    port?: number;           // 端口号（可选）
    model?: string;          // 设备型号（可选）
    manufacturer?: string;   // 制造商（可选）
    firmwareVersion?: string; // 固件版本（可选）
  };
  
  // 时间信息
  timeInfo: {
    serverTime: string;      // 服务器时间 (ISO 8601 格式)
    timezone: string;        // 时区 (如: "Asia/Shanghai")
    uptime?: number;         // 运行时长（秒，可选）
  };
  
  // 摄像头信息
  cameras: {
    total: number;           // 摄像头总数
    online: number;          // 在线数量
    offline: number;         // 离线数量
    list: CameraInfo[];      // 摄像头列表
  };
  
  // 扩展信息（可选，供第三方扩展使用）
  extensions?: Record<string, any>;
}

interface CameraInfo {
  id: string;                // 摄像头 ID
  name: string;              // 摄像头名称
  status: 'online' | 'offline'; // 状态
  channel?: number;          // 通道号（可选）
  resolution?: string;       // 分辨率（可选，如: "1920x1080"）
  streamUrl?: string;        // 流地址（可选）
}
```

### 3.2 API 调用规范

**调用方式：**
- ✅ **主应用负责调用 API**：接口由主应用调用，插件不直接调用 API
- ✅ **数据传递**：主应用获取数据后，通过属性或方法传递给插件
- ✅ **认证处理**：主应用负责处理认证（JWT Token），插件无需关心

**数据流：**
1. 主应用调用 API 获取 `DeviceOverviewData`
2. 主应用将数据传递给插件组件
3. 插件接收数据并渲染

## 4. 插件开发规范

### 4.1 Web Component 规范

**组件命名：**
- 自定义元素名称必须以 `device-overview-` 开头
- 例如：`device-overview-custom`, `device-overview-partner-a`

**组件接口：**
```typescript
interface DeviceOverviewPlugin extends HTMLElement {
  // 属性
  data: string;  // 设备概况数据（JSON 字符串格式）
  
  // 方法（可选）
  updateData(data: DeviceOverviewData): void;  // 更新数据
}
```

**数据传递方式：**
- 方式一：通过 `data` 属性传递 JSON 字符串
- 方式二：通过 `updateData()` 方法传递数据对象
- 插件监听属性变化或方法调用，更新渲染内容

### 4.2 插件实现示例

```javascript
// 第三方插件示例：device-overview-custom.js
class DeviceOverviewCustom extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this._data = null;
  }

  static get observedAttributes() {
    return ['data'];
  }

  connectedCallback() {
    this.render();
    // 如果已有数据，立即渲染
    if (this._data) {
      this.renderData(this._data);
    }
  }

  attributeChangedCallback(name, oldValue, newValue) {
    if (name === 'data' && oldValue !== newValue && this.isConnected) {
      try {
        this._data = JSON.parse(newValue);
        this.renderData(this._data);
      } catch (e) {
        console.error('Failed to parse data:', e);
      }
    }
  }

  // 通过方法更新数据（可选）
  updateData(data) {
    this._data = data;
    this.renderData(data);
  }

  render() {
    this.shadowRoot.innerHTML = `
```

### 4.3 插件打包要求

**文件格式：**
- 单个 JS 文件（UMD 格式或 ES Module）
- 文件名建议：`device-overview-{partner-name}.js`

**依赖要求：**
- 插件应该尽量少依赖外部库
- 如需依赖，建议使用 CDN 或打包进插件文件
- 不能依赖主应用的框架（Vue/React 等）

**浏览器兼容性：**
- 支持现代浏览器（Chrome 90+, Firefox 88+, Safari 14+, Edge 90+）
- 如需支持旧浏览器，需要提供 polyfill

## 5. 主应用集成方案

### 5.1 插件加载器实现

```typescript
// PluginLoader.ts
interface PluginConfig {
  name: string;              // 插件名称（用于标识）
  url: string;               // 插件 JS 文件 URL
  componentName: string;     // Web Component 名称
}

class PluginLoader {
  private loadedPlugins = new Set<string>();

  /**
   * 加载插件
   */
  async loadPlugin(config: PluginConfig): Promise<void> {
    const { name, url, componentName } = config;
    
    // 检查是否已加载
    if (this.loadedPlugins.has(name)) {
      return;
    }

    // 动态加载 JS 文件
    await this.loadScript(url);
    
    // 检查组件是否已注册
    if (!customElements.get(componentName)) {
      throw new Error(`Component ${componentName} not found after loading plugin`);
    }

    this.loadedPlugins.add(name);
  }

  private loadScript(url: string): Promise<void> {
    return new Promise((resolve, reject) => {
      const script = document.createElement('script');
      script.src = url;
      script.type = 'text/javascript';
      script.async = true;
      
      script.onload = () => resolve();
      script.onerror = () => reject(new Error(`Failed to load script: ${url}`));
      
      document.head.appendChild(script);
    });
  }

  /**
   * 创建插件实例
   */
  createPluginInstance(componentName: string): HTMLElement {
    return document.createElement(componentName);
  }

  /**
   * 更新插件数据
   */
  updatePluginData(element: HTMLElement, data: DeviceOverviewData): void {
    // 方式一：通过属性传递（JSON 字符串）
    element.setAttribute('data', JSON.stringify(data));
    
    // 方式二：通过方法传递（如果插件支持）
    if (typeof (element as any).updateData === 'function') {
      (element as any).updateData(data);
    }
  }
}
```

### 5.2 Vue 组件封装示例

```vue
<template>
  <div class="device-overview-plugin-container">
    <div v-if="loading" class="loading">加载插件中...</div>
    <div ref="pluginContainer" v-show="!loading"></div>
  </div>
</template>

<script>
import { PluginLoader } from './PluginLoader';
import { getDeviceOverview } from '@/api/device'; // 假设的 API 调用方法

export default {
  name: 'DeviceOverviewPlugin',
  props: {
    pluginUrl: {
      type: String,
      required: true
    },
    componentName: {
      type: String,
      required: true
    },
    serverId: {
      type: String,
      required: true
    }
  },
  data() {
    return {
      loading: false,
      pluginLoader: new PluginLoader(),
      pluginElement: null,
      deviceData: null
    };
  },
  async mounted() {
    await this.initPlugin();
    await this.loadDeviceData();
  },
  watch: {
    // 监听数据变化，更新插件
    deviceData(newData) {
      if (newData && this.pluginElement) {
        this.updatePluginData();
      }
    }
  },
  methods: {
    async initPlugin() {
      this.loading = true;

      // 加载插件
      await this.pluginLoader.loadPlugin({
        name: this.componentName,
        url: this.pluginUrl,
        componentName: this.componentName
      });

      // 创建插件实例
      this.pluginElement = this.pluginLoader.createPluginInstance(this.componentName);

      // 挂载到容器
      this.$refs.pluginContainer.appendChild(this.pluginElement);

      this.loading = false;
    },

    async loadDeviceData() {
      // 主应用调用 API 获取数据
      try {
        const response = await getDeviceOverview(this.serverId);
        if (response.code === 200) {
          this.deviceData = response.data;
        }
      } catch (error) {
        console.error('Failed to load device data:', error);
      }
    },

    updatePluginData() {
      if (this.pluginElement && this.deviceData) {
        // 更新插件数据
        this.pluginLoader.updatePluginData(this.pluginElement, this.deviceData);
      }
    }
  },
  beforeDestroy() {
    // 清理插件实例
    if (this.$refs.pluginContainer && this.pluginElement) {
      this.$refs.pluginContainer.removeChild(this.pluginElement);
    }
  }
};
</script>

<style scoped>
.device-overview-plugin-container {
  width: 100%;
  min-height: 200px;
}

.loading {
  padding: 20px;
  text-align: center;
}
</style>
```

## 6. 安全考虑

### 6.1 内容安全策略 (CSP)

**建议配置：**
- 限制插件只能从指定域名加载
- 限制插件的内联脚本执行
- 使用 nonce 或 hash 验证插件脚本

### 6.2 API 安全

**API 调用安全：**
- ✅ 主应用负责 API 调用，插件不直接访问 API
- ✅ 主应用处理认证（JWT Token），插件无需接触 Token
- ✅ 后端验证 Token 有效性和服务器 ID 访问权限
- ✅ 限制 API 调用频率（防止滥用）

### 6.3 插件安全

**沙箱隔离：**
- Web Components 的 Shadow DOM 提供样式隔离
- 插件无法直接访问主应用的全局对象
- 插件只接收数据，不执行网络请求

**代码审查：**
- 第三方插件需要经过安全审查
- 建议使用白名单机制，只允许审核通过的插件
