# 任务编辑功能改动分析

## 📋 需求概述

1. 支持任务编辑功能（左键点击编辑，需区分点击和拖动）
   - ✅ **已完成任务不允许编辑**
   - ✅ **右键不触发编辑，而是触发右键菜单，并在右键菜单中新增编辑选项**
2. 新增「任务详情」字段
3. 任务标题文字过长时单行省略显示（不换行）
4. 区分「拖动时的任务预览」和「象限内的任务卡片」
5. **合并编辑与新增弹窗为统一组件**
6. **TaskCard 中不显示 description，但需要有图标区分有无详情**

### 2. 编辑功能实现

#### 2.1 点击 vs 拖动的区分策略

**问题分析：**
- 当前 `TaskCard.tsx` 中，任务内容区域绑定了 `{...listeners}` 作为拖拽监听器
- 用户点击时会触发拖拽，而不是编辑

**解决方案：使用「拖拽阈值」或「延迟启动」**

**方案 A：使用 @dnd-kit 的 `activationConstraint`（推荐）**

```typescript
// 在 useSortable 或 useDraggable 中配置
useSortable({
  id: task.id,
  disabled: task.completed,
  // 新增：拖拽激活约束
  // 需要移动一定距离或按住一定时间才会触发拖拽
})

// 在 DndContext 的 sensors 中配置
const sensors = useSensors(
  useSensor(PointerSensor, {
    activationConstraint: {
      // 方案1：移动距离阈值（推荐）
      distance: 8, // 移动 8px 后才激活拖拽
      
      // 方案2：延迟时间阈值
      // delay: 150, // 按住 150ms 后才激活拖拽
      // tolerance: 5,
    },
  })
)
```

**核心逻辑：**
- 用户点击后立即松开 → 触发编辑
- 用户点击后拖动超过 8px → 触发拖拽

#### 2.2 编辑对话框/弹窗（合并方案）

**方案：将 `AddTaskDialog.tsx` 重构为 `TaskFormDialog.tsx`（添加/编辑共用）**

```typescript
interface TaskFormDialogProps {
  open: boolean
  mode: 'add' | 'edit'  // 模式：添加或编辑
  task?: Task | null    // 编辑时传入任务数据，添加时为 undefined
  quadrant?: QuadrantType  // 添加时传入象限，编辑时从 task 中获取
  onOpenChange: (open: boolean) => void
  onConfirm: (data: { title: string; description?: string }) => void
}
```

**表单字段：**
- 任务标题（title）
- 任务详情（description）- 新增（使用 Textarea 组件）

**对话框标题：**
- 添加模式：`添加任务`
- 编辑模式：`编辑任务`

**表单默认值：**
- 添加模式：`title: ''`, `description: ''`
- 编辑模式：`title: task.title`, `description: task.description || ''`

#### 2.4 TaskCard 点击事件处理

**重要变更：**
1. **已完成任务不允许编辑** - 已完成任务不绑定点击事件
2. **右键不触发编辑** - 右键事件由 `TaskContextMenu` 处理，显示右键菜单
3. **左键点击触发编辑** - 仅未完成任务支持左键点击编辑

```typescript
// TaskCard.tsx 改动示意
export default function TaskCard({ 
  task, 
  hoverColor, 
  onToggleComplete, 
  onDelete,
  onEdit,  // 新增
}: TaskCardProps) {
  // ...

  // 点击处理（仅未完成任务支持编辑）
  const handleClick = (e: React.MouseEvent) => {
    // 阻止事件冒泡，避免触发其他事件
    e.stopPropagation()
    
    // 已完成任务不允许编辑
    if (task.completed) return
    
    // 拖拽未激活时触发编辑
    if (!isDragging) {
      onEdit?.(task)
    }
  }

  return (
    <TaskContextMenu 
      taskId={task.id}
      isCompleted={task.completed}
      onEdit={() => onEdit?.(task)}  // 右键菜单中的编辑选项
      onDelete={onDelete}
    >
      <div ...>
        <Checkbox ... />
        
        {/* 内容区域 */}
        <div
          {...(task.completed ? {} : listeners)}
          onClick={handleClick}  // 新增点击事件（仅未完成任务）
          className={cn(
            // 已完成任务：普通光标；未完成任务：可点击光标
            task.completed ? 'cursor-default' : 'cursor-pointer'
          )}
        >
          {/* 任务标题 + 详情图标 */}
          <span ...>{task.title}</span>
          {/* 详情图标（见第 5 节） */}
        </div>
      </div>
    </TaskContextMenu>
  )
}
```

### 3. 任务详情图标显示

#### 3.1 需求说明

- TaskCard 中**不显示 description 文本**（保持简洁）
- 通过**图标**区分有无详情：
  - 有详情：显示图标（如 `FileText` 或 `Info`）
  - 无详情：不显示图标

#### 3.2 图标选择建议

使用 `lucide-react` 图标库：
- `FileText` - 文件图标，表示有详情
- `Info` - 信息图标
- `AlignLeft` - 文本对齐图标

**推荐：`FileText`**，更直观表示"有文本内容"。

#### 3.3 TaskCard 改动

```typescript
// TaskCard.tsx
import { FileText } from 'lucide-react'

// 在任务标题后添加图标
<div
  {...(task.completed ? {} : listeners)}
  onClick={handleClick}
  className={cn(...)}
>
  <span className={cn('text-sm truncate', ...)}>
    {task.title}
  </span>
  
  {/* 详情图标（仅在有详情时显示） */}
  {task.description && task.description.trim() && (
    <FileText className="h-3.5 w-3.5 text-muted-foreground shrink-0 ml-1.5" />
  )}
</div>
```

**样式说明：**
- `h-3.5 w-3.5` - 小尺寸图标
- `text-muted-foreground` - 使用次要文字颜色
- `shrink-0` - 防止 flex 布局时图标被压缩
- `ml-1.5` - 与标题保持间距

#### 3.4 DraggedTaskPreview 同步改动

拖拽预览也需要显示详情图标：

```typescript
// DraggedTaskPreview.tsx
import { FileText } from 'lucide-react'

  <Checkbox checked={task.completed} disabled />
  
  <span className={cn('text-sm truncate', ...)}>
    {task.title}
  </span>
  
  {/* 详情图标 */}
  {task.description && task.description.trim() && (
    <FileText className="h-3.5 w-3.5 text-muted-foreground shrink-0 ml-1.5" />
  )}
</div>
```

### 4. 文字过长单行省略显示

#### 3.1 当前问题

`TaskCard.tsx` 中任务标题没有限制宽度和溢出处理，长文本会导致换行。

#### 3.2 改动方案

**文件：`TaskCard.tsx`**

```typescript
// 当前代码
<span
  className={cn(
    'text-sm',
    task.completed && 'line-through text-muted-foreground'
  )}
>
  {task.title}
</span>

// 改动后
<span
  className={cn(
    'text-sm truncate',  // 新增 truncate（单行省略）
    task.completed && 'line-through text-muted-foreground'
  )}
  title={task.title}  // 新增 title 属性，hover 显示完整文本
>
  {task.title}
</span>
```

**同时需要确保父容器有 `overflow-hidden` 或宽度限制：**

```typescript
// 内容区域需要添加 min-w-0 和 overflow-hidden
<div
  {...(task.completed ? {} : listeners)}
  className={cn(
    'flex-1 flex items-center h-full py-3 min-w-0',  // 新增 min-w-0
    task.completed ? 'cursor-default' : 'cursor-grab active:cursor-grabbing'
  )}
>
  <span className={cn('text-sm truncate', ...)}>
    {task.title}
  </span>
</div>
```

**Tailwind CSS 说明：**
- `truncate` = `overflow-hidden text-overflow-ellipsis whitespace-nowrap`
- `min-w-0` 允许 flex 子元素收缩到小于其内容宽度

### 5. 拖动预览与象限任务卡片的区分

#### 5.1 当前架构说明

| 组件 | 用途 | 显示时机 |
|------|------|----------|
| `TaskCard` | 象限内的任务卡片 | 始终显示在象限中 |
| `DraggedTaskPreview` | 拖拽时跟随鼠标的预览 | 仅在拖拽过程中显示（DragOverlay 内） |

**这是两个独立的组件，样式需要分别维护。**

#### 4.2 样式对比

| 属性 | TaskCard | DraggedTaskPreview |
|------|----------|-------------------|
| 背景 | `bg-card/80 backdrop-blur-sm` | `bg-card` |
| 边框 | `border border-border/50` | `border border-border` |
| 阴影 | hover 时显示 | `shadow-lg`（始终显示） |
| 透明度 | 拖拽中 `opacity: 0.3` | `opacity-90` |
| 交互 | 可点击、拖拽 | 禁用（仅显示） |

#### 5.3 建议改动

如果需要保持两者样式一致，可以：

1. **提取公共样式常量**

```typescript
// config.ts 或单独的 styles.ts
export const TASK_CARD_BASE_STYLES = cn(
  'flex items-center gap-2 px-3 py-3 rounded-lg',
  'bg-card/80 backdrop-blur-sm border border-border/50'
)
```

2. **两个组件都使用该常量**

这样修改样式时只需改一处。

## 📌 关键变更点总结

### 1. 编辑功能交互逻辑

| 操作 | 未完成任务 | 已完成任务 |

- **TaskCard**：不显示 description 文本，通过 `FileText` 图标标识

- **已有实现**：`TaskContextMenu.tsx` 中已有编辑选项
