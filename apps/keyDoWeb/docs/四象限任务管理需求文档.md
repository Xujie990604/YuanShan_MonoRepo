# 四象限任务管理功能需求文档

## 📋 项目概述

在 keyDoWeb 首页实现一个基于**艾森豪威尔矩阵（Eisenhower Matrix）**的任务管理系统，采用 2×2 四象限布局，支持任务拖拽功能。

**参考应用：** 滴答清单（TickTick）

## ✅ 需求确认状态

| 需求项 | 状态 | 确认内容 |
|--------|------|----------|
| 象限背景色 | ✅ 已确认 | 方案 A（柔和色系） |
| 添加任务方式 | ✅ 已确认 | 每个象限右上角 `+` 按钮 |
| 删除任务方式 | ✅ 已确认 | 右键菜单 |
| 已完成任务 | ✅ 已确认 | 默认不折叠，单独成组 |
| 数据存储 | ✅ 已确认 | localStorage（后续有接口后变更） |

## 🎯 核心功能需求

### 1. 四象限布局

#### 1.1 象限定义（✅ 已确认：使用 Q1-Q4）
- **象限 Q1（重要且紧急）**：左上角
- **象限 Q2（重要不紧急）**：右上角
- **象限 Q3（不重要但紧急）**：左下角
- **象限 Q4（不重要不紧急）**：右下角

#### 1.2 布局要求
- 2×2 网格布局，每个象限占据相等的空间
- 每个象限有独立的背景色（用于视觉区分）
- 每个象限显示标题和任务数量
- 空象限显示"暂无任务"提示文字（✅ 已确认）
- 暂不考虑移动端响应式（✅ 已确认）

### 2. 任务管理

#### 2.1 任务数据结构
```typescript
interface Task {
  id: string;              // 唯一标识
  title: string;           // 任务标题
  quadrant: QuadrantType;  // 所属象限：'Q1' | 'Q2' | 'Q3' | 'Q4'
  completed: boolean;      // 是否完成
  createdAt: string;       // 创建时间
  updatedAt: string;       // 更新时间
  // 可选字段（未来扩展）
  dueDate?: string;        // 截止日期
  priority?: 'low' | 'medium' | 'high';  // 优先级
  tags?: string[];         // 标签
  description?: string;    // 描述
}
```

#### 2.2 任务显示
- 每个任务显示为卡片形式
- 显示任务标题
- 显示完成状态（复选框）
- 支持任务完成/取消完成
- 支持任务删除（待确认交互方式）

#### 2.3 任务分组
- 按完成状态分组：未完成任务、已完成任务
- 已完成任务默认不折叠（✅ 已确认）
- 显示各分组的任务数量

### 3. 拖拽功能

#### 3.1 拖拽范围
- 任务可以**跨象限**拖拽（改变象限归属）
- 暂不考虑象限内任务排序（✅ 已确认）

#### 3.2 拖拽交互
- 拖拽时显示视觉反馈（拖拽中的任务样式变化）
- 拖拽目标区域高亮显示
- 拖拽完成后更新任务状态
- 支持拖拽动画效果

#### 3.3 技术实现
- 使用 **@dnd-kit/core** 作为核心库
- 使用 **@dnd-kit/sortable** 实现排序
- 使用 **@dnd-kit/utilities** 工具函数

### 4. 左侧工具栏

#### 4.1 当前功能
- 显示用户头像（Avatar）
- 头像可点击（功能待定：个人设置？）

#### 4.2 未来扩展（预留）
- 导航菜单
- 设置入口
- 搜索功能
- 其他快捷操作

### 4. 拖拽实现

#### 4.1 DnD Context 设置
```typescript
import { DndContext, DragEndEvent } from '@dnd-kit/core';

<DndContext onDragEnd={handleDragEnd}>
  {/* 四象限内容 */}
</DndContext>
```

#### 4.2 Sortable Context
- 每个象限使用 `SortableContext`
- 任务卡片使用 `useSortable` hook
- 支持跨象限拖拽

#### 4.3 拖拽处理逻辑
```typescript
const handleDragEnd = (event: DragEndEvent) => {
  const { active, over } = event;
  
  if (!over) return;
  
  // 判断是否跨象限
  const activeQuadrant = getQuadrantFromId(active.id);
  const overQuadrant = getQuadrantFromId(over.id);
  
  if (activeQuadrant !== overQuadrant) {
    // 跨象限移动
    moveTaskToQuadrant(active.id, overQuadrant);
  } else {
    // 同象限内排序
    reorderTasksInQuadrant(activeQuadrant, active.id, over.id);
  }
};
```

## 🔄 交互流程

### 1. 页面加载
1. 显示左侧工具栏（头像）
2. 显示 2×2 四象限布局
3. 从 localStorage 加载任务数据（如无数据则使用初始 Mock 数据）
4. 按象限和完成状态分组显示任务

### 2. 添加任务（✅ 已确认）
- 每个象限右上角有 `+` 按钮
- 点击 `+` 按钮弹出添加任务对话框
- 输入任务标题后自动添加到对应象限

### 3. 完成任务
- 点击任务复选框或任务标题
- 任务移动到"已完成"分组
- 更新任务状态

### 4. 拖拽任务
- 鼠标按下任务卡片开始拖拽
- 拖拽过程中显示视觉反馈
- 拖拽到目标象限/位置后释放
- 更新任务位置和排序

### 5. 删除任务（✅ 已确认）
- 右键点击任务卡片显示上下文菜单
- 菜单中包含"删除"选项
- 确认删除后从列表中移除任务
